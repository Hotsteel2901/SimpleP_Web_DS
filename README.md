# SimplePlanes 2 · three.js 复刻版

用 **three.js** 从零复刻 Jundroo《简单飞机 2（SimplePlanes 2）》核心体验的浏览器游戏：
**程序化建造 → 真实飞行物理 → 9 张可玩地图 → 竞速/空战/货运/降落等玩法 → 实时合成的音乐音效**。

> 全部资源都是**运行时程序化生成**的：没有一张贴图、没有一个音频文件、没有一次网络请求。
> 地形、建筑、飞机模型、HUD、音乐、引擎声全部由代码算出来。

---

## 亮点

- **桌面 + 移动端**：同一套物理与输入管线，手机上自动切换为触屏操纵（虚拟摇杆 + 油门滑条 + 按钮簇），菜单自适应横竖屏。
- **P2P 联机 + 公网中继**：WebRTC 直连优先，打洞失败自动退回服务器中继，最多 16 人同房间；带服务器浏览器、房间设置、聊天、踢人、房主迁移。
- **9 张地图 / 11 种玩法 / 程序化建造 / 实时合成音乐音效**。

## 快速开始

```bash
npm install          # 只依赖 three.js
npm start            # 启动本地静态服务器（零依赖，默认 8080）
# 打开 http://localhost:8080
```

> ⚠️ 必须通过 HTTP 打开（ES Module 的同源限制），直接双击 `index.html` 会失败。

首次点击/按键后才会开启声音（浏览器策略要求用户手势）。

### 移动端

- 手机上打开同一个地址即可，首次触摸会尝试**全屏 + 锁定横屏**。
- 自动切换到**触屏操纵**并把画质降到「低」（阴影关闭），可以在设置里改回来。
- 触屏布局：左拇指**虚拟摇杆**（俯仰/滚转，按下即出现在拇指位置）、右侧**油门滑条**（保持不回落）、右下**按钮簇**（机炮/导弹/炸弹/干扰弹/起落架/襟翼/刹车/视角/重置/伞）、右下角小摇杆或 左舵/右舵 按钮控制偏航。
- 所有可点区域 ≥ 44 px，并避让刘海与home指示条（`env(safe-area-inset-*)`）；竖屏会提示横屏。
- 机库同样支持触屏：单指旋转/选中/拖拽零件，双指捏合缩放、双指拖动平移。

## 联机（P2P + 公网中继）

```bash
npm start            # 服务器同时提供静态文件 + 信令/中继（WebSocket，路径 /ws）
```

1. 主菜单 → **🌐 联机对战** → **创建服务器**（房间名 / 最大人数 / 可见性 / 地图 / 玩法 / 同步频率 / 零件上限）。
2. 其他人打开同一地址 → **联机对战** → 在列表里点房间加入（私人房间用房间号加入）。
3. 进入房间后房主可以先切**时间/天气/同步频率**，然后点「进入战场」。

**连接策略**（自动，无需配置）：

| 情况 | 走法 | 说明 |
|---|---|---|
| 双方能打洞成功 | **P2P 直连**（WebRTC DataChannel） | 延迟最低，不经过服务器 |
| 对称 NAT / 运营商 CGNAT / 无法打洞 | **公网中继**（服务器转发） | 玩法完全一致，延迟略高；4 秒内没连上就自动切换 |
| 自建 TURN | 在设置里填 `turn:host:3478` + 用户名/密码 | 对称 NAT 下也能走 P2P 中继（延迟更低） |
| 服务器不可达 | 单机继续 | 联机模块静默降级，不影响单机 |

同步模型：本地飞机以 5–30 Hz（房主可调）广播位置/姿态/转速/血量，远端用 **100 ms 延迟插值**渲染成「幽灵机」，不参与本地物理；命中由**射击方**判定、伤害事件发给**目标宿主**由其本机权威结算；房主掉线自动迁移。

部署到公网：把项目放到任意 Node 主机上 `node server.js`，前面套 HTTPS/WSS 反代（`wss://你的域名/ws`），在设置里填写该地址即可跨公网联机。

### 界面层级（曾经踩过的坑）

菜单、建造器、HUD、触屏控件全部位于 `#ui` **同一个层叠上下文**内，层级固定为
`HUD(20) < 菜单(40) < 建造器(60) < 弹窗/Toast`。加上 `App.setState()` 这个唯一的状态切换入口会同步所有覆盖层显隐，以及主循环里的自愈兜底（飞行/建造状态下若菜单仍可见就自动关闭），
不会再出现「起飞后菜单收不回去」「建造器被主菜单盖住点不动」这类问题。
`tests/boot-smoke.mjs` 里有对应断言锁住这些行为。

### 飞行动力学要点

- **刚体**：半隐式欧拉积分 + 四元数姿态 + 由零件点质量累加得到的惯性张量（`R·I·Rᵀ` 求逆）。
- **气动**：每个翼面独立求解 —— 有限展弦比升力线斜率 `2πAR/(AR+2)`、失速后过渡到平板理论、
  诱导阻力 `CL²/(πARe)`、**机翼下洗**（尾翼有效迎角降低，缺了它飞机只会低头）。
- **操纵面**：副翼/升降舵/方向舵的偏转直接改变该翼面升力，因此力矩是**自然产生**的；
  舵面方向按“在重心之前还是之后”“在左侧还是右侧”自动映射（鸭翼会自动反向）。
- **起落架**：弹簧-阻尼悬挂（对称阻尼，避免抽能振荡）、静摩擦轮胎模型（不再低速漂移）、
  前轮转向、渐进式缓冲；出生时用**静平衡姿态求解**消除砸地。
- **平台支撑**：起落架会自动识别屋顶、航母甲板、桥梁等盒体作为可停放面。
- **损毁**：零件逐个脱落并抛飞，质量与惯性实时重算。

### 逐零件损毁（对齐原版）

- **每个零件独立血量**（按体积开立方定标：小零件脆、大零件耐撞），伤害落在**撞击点附近的零件**上，
  而不是整机扣一个总血量。子弹用很小的半径（几乎只打到被命中的那个零件），撞地/爆炸影响一片。
- **撞击按动能结算**：用接触点沿地面法线的速度，`dmg ≈ v²·0.8·(0.6+0.4·min(1, m/1500))`。

  | 垂直速度 | 结果 |
  |---|---|
  | ≤3 m/s | 正常着陆，不掉血 |
  | 6 m/s | 轻擦：撞击点零件掉血、外壳变暗，飞机照常飞 |
  | 15 m/s | 重着陆：撞到的零件基本报废、可能脱落 |
  | ≥20 m/s | 断件飞舞，结构散架 |
  | ≥300 伤害一击（约 26 m/s 撞地） | 直接爆炸 |

- **零件血量归零就脱落**：模型变碎片抛飞（落地有碎屑声），并且**连带失效**——掉了发动机就没推力、
  掉了机翼就没升力、掉了油箱就漏油、掉了起落架就没轮子。质量与惯性同步重算。
- **关键件（座舱/飞行员）损毁 = 整机损毁**；结构剩余血量低于 22% 也判定散架。
- **外观反馈**：零件受伤变暗，重伤自发光红热。
- **音效**：蹭地 `scrape`、断裂 `metal_break`、机翼撕裂 `wing_tear`、发动机故障 `engine_sputter`、
  碎片落地 `debris_fall`、中弹 `hull_hit`/`hull_hit_big`、结构告警 `damage_alarm`、整机爆炸 `explosion_big`。
  全部带 60ms 同名节流与并发上限（同名 6、总计 20），狂触发也不会爆音。

### 音频（纯合成，无音频文件）

- 引擎：活塞（锯齿 + 气缸脉冲 + 带通噪声）、涡喷（高通噪声 + 低频轰鸣）等 5 种音色，随转速/油门平滑变化。
- 音效 31 种：爆炸、机炮、导弹发射、失速警告、触地、水花、开伞、光环通过……
- 音乐 10 首：菜单、机库、自由飞行、竞速、空战、雪原、沙漠、城市、胜利、失败。
  每首有独立的速度/调式/和弦进行与配器，用前瞻式步进音序器实时演奏，切换时交叉淡入。
  3D 定位走 `PannerNode`，共享程序化脉冲响应混响 + 母带压缩。

### 已修复的典型问题（测试发现）

- 起落架减振器只做压缩阻尼导致**抽能振荡**，飞机在地面会自己翻掉 → 改为对称阻尼
- 缺少**机翼下洗**，尾翼迎角与主翼相同 → 飞机一起飞就低头俯冲
- 副翼左右方向、鸭翼（重心之前）的舵效方向、方向舵法线朝向都需要按几何位置自动映射
- 静摩擦轮胎模型：原来的黏性摩擦让飞机在跑道上持续偏航漂移
- 出生姿态用**弹簧静平衡**求解，消除“砸地弹飞”
- 库存机型的重心/主起落架位置由 `autoBalance()` 自动配平，否则重机型无法抬轮
- 原来的"整机一个血条"改成逐零件损毁：伤害必须落到具体零件上，否则轻擦也会整机掉血
- 撞击伤害一开始用总速度计算，导致 30 m/s 的正常着陆速度就"摔机"→ 改用接触点法向速度

## 性能

- 地形 3.6 万–5.1 万三角（测试用低分段），实际默认分段约 20 万三角
- 地标每张图 13–193 个碰撞体、67–305 个 draw call、8 万–28 万三角
- 树木用 `InstancedMesh`（每张图 588–2352 棵，每物种 1 次绘制）
- 物理固定步长 1/120 s，每帧最多 5 个子步；所有热路径零分配
- 画质三档：低（无阴影）/ 中（阴影 + 细节）/ 高（更高分辨率 + 更多粒子）
